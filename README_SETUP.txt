ΣΤΟΧΟΣ v2 — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ (05/11/2026)

1. ΠΑΡΕ ΑΝΤΙΓΡΑΦΟ ΑΣΦΑΛΕΙΑΣ του site και του Firestore.
2. Στο Firebase Console > Firestore Database > Rules επικόλλησε το νέο firestore.rules και Publish.
3. Ανέβασε ΜΑΖΙ τα index.html, style.css, script.js, firebase-auth.js, brand-icon.png, favicon-32.png, apple-touch-icon.png, og-preview.jpg και τα δύο ΑΜΕΤΑΒΛΗΤΑ αρχεία ερωτήσεων.
4. Για Premium εξαίρεση: Firebase Console > Authentication > Users > αντιγραφή UID του δικού σου λογαριασμού. Firestore > Start collection «entitlements» > Document ID = ακριβώς UID > πρόσθεσε πεδίο premium τύπου boolean με τιμή true. Αποθήκευσε. ΜΗΝ βάζεις email σε κανόνες JS. Ο λογαριασμός θα έχει απεριόριστες καταχωρίσεις ολοκληρωμένων τεστ.
5. Δοκίμασε σύνδεση, δωρεάν και Premium λογαριασμό, αποθήκευση αποτελεσμάτων, ιστορικό και κοινωνική προεπισκόπηση.

ΣΗΜΑΝΤΙΚΟ:
- Ο μετρητής users/{uid}.started διατηρεί το παλιό όνομα για συμβατότητα. Στη v2 μετρά ΟΛΟΚΛΗΡΩΜΕΝΑ δωρεάν τεστ (3). Οι ΠΑΛΙΕΣ καταχωρισμένες ενάρξεις δεν διαγράφονται/μετατρέπονται αυτομάτως. Για υφιστάμενους λογαριασμούς θέλει προσεκτική μετάβαση δεδομένων.
- Αν διακοπεί ένα τεστ, δεν καταναλώνει ολοκλήρωση. Αν διακοπεί μετά από επιτυχημένη καταχώριση δεν επιστρέφεται.
- Τα αποτελέσματα παραμένουν client-generated και μπορούν να παραποιηθούν από τεχνικά ικανό χρήστη. Το Firestore εγγυάται μόνο την ατομική καταχώριση / quota και τη δομική εγκυρότητα — για πραγματική anti-cheat επαλήθευση χρειάζεται backend που παραδίδει και βαθμολογεί τις ερωτήσεις.
- Οι ερωτήσεις είναι δημόσια JavaScript και δεν αποτελούν προστατευμένο paywall.
- Τα δύο αρχεία ερωτήσεων αντιγράφηκαν χωρίς καμία αλλαγή.
- Συνδρομές δεν χρεώνονται και δεν έχουν προστεθεί.
